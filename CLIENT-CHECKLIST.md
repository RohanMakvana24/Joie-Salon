# Joie Salon — Client પાસેથી લેવાની checklist

આ websiteમાં હાલ કેટલીક AI/demo images, services, products અને descriptions છે. નીચેની વિગતો salon owner પાસેથી confirm કર્યા પછી final content મૂકવાનું છે.

## 1. Salon અને contact details — જરૂરી

- [ ] Salonનું official નામ અને Gujarati/English spelling.
- [ ] Owner / website approval આપનાર વ્યક્તિનું નામ અને contact.
- [ ] હાલ websiteમાં રહેલો **+91 82828 48453** number તમારો જ છે તેની confirmation.
- [ ] આ number પર WhatsApp booking messages મળે છે તેની confirmation. અલગ booking number હોય તો આપવો.
- [ ] Public calling number અને WhatsApp number website પર બતાવવાની મંજૂરી.
- [ ] સંપૂર્ણ address, landmark, pincode અને exact Google Maps business link/pin.
- [ ] દર દિવસના opening/closing hours, weekly off અને holiday arrangements.
- [ ] Official Instagram, Facebook, YouTube અને Google Business Profile / reviews links. Account ન હોય તો જણાવવું.

## 2. Services, rates અને packages — જરૂરી

- [ ] ખરેખર આપવામાં આવતી servicesની list: haircut, fade, beard, shave, kids cut, hair colour, hair spa, facial વગેરે.
- [ ] દરેક serviceનો current rate / starting rate અને અંદાજિત duration.
- [ ] Rates public બતાવવાના છે કે “WhatsApp for pricing” રાખવાનું છે?
- [ ] Packagesનાં સાચાં નામ, included services, duration અને price.
- [ ] Wedding/event/home-visit service આપો છો? આપતા હો તો areas, minimum group size, travel charge અને advance notice.
- [ ] હાલના offers, eligibility અને offer end date. Offer ન હોય તો બનાવવાનો નથી.
- [ ] Payment modes, advance/deposit હોય તો amount, cancellation/reschedule policy.
- [ ] Salonમાં ખરેખર available facilities: AC, Wi-Fi, parking વગેરે. Hygiene વિશે publish કરવાની વિગતો owner confirm કરે.

## 3. Original photos અને logo — જરૂરી

WhatsAppમાં શક્ય હોય ત્યાં **Document / original file** તરીકે મોકલવા, જેથી image quality ઘટે નહીં.

- [ ] Official logo: SVG / transparent PNG / original PDF. ન હોય તો હાલના logo માટે approval.
- [ ] Shop બહારના 2–3 clear photos: signboard અને entrance દેખાવા જોઈએ.
- [ ] Interiorના 4–6 photos: chairs, mirrors, workstation અને waiting area.
- [ ] Salon owner / lead barberના 1–2 portraits અને કામ કરતા 2–3 candid photos.
- [ ] સાચા haircut / beard workના ઓછામાં ઓછા 8–12 clear photos.
- [ ] શક્ય હોય તો 3–5 matching before/after pairs, સમાન angle અને lightingમાં.
- [ ] Team section રાખવો હોય તો દરેક actual staff memberનું નામ, role અને portrait.
- [ ] Product section રાખવો હોય તો actual product photos, brand, size, price અને availability. Products વેચતા ન હો તો section દૂર કરવો.
- [ ] Photos/videoમાં દેખાતા customers અને staffની website/social use માટે મંજૂરી. બાળકો માટે parent/guardianની મંજૂરી.
- [ ] મોકલેલા logo/photos/video વાપરવાનો અધિકાર salon પાસે છે તેની confirmation.

## 4. Brand અને content approval

- [ ] Salon વિશે 3–5 સાચી વાતો: speciality, ownerનો experience, establishment year જો ખાતરી હોય તો.
- [ ] Website Gujarati, English કે બંને ભાષામાં જોઈએ?
- [ ] Final logo, colours અને overall design પર approval.
- [ ] Reviews માટે original source links અને publish કરવાની મંજૂરી. Rating/count source અને date સાથે confirm કરવાં.
- [ ] Blog guides owner review કરે: services અથવા results અંગે ખોટા promises ન રહે.
- [ ] AIથી બનાવેલા illustrative visuals કયા sectionsમાં રાખવા અને કયા original photosથી બદલવા તેની પસંદગી.

## 5. AIનો ઉપયોગ કેવી રીતે કરવો

- Original photosમાં crop, exposure, background cleanup, consistent sizing અને website compression કરી શકાય.
- Service descriptions, Gujarati/English copy અને blog drafts AIની મદદથી તૈયાર કરીને owner પાસેથી approve કરાવવા.
- Ownerની મંજૂરીથી decorative illustrations / style inspiration બનાવી શકાય; જરૂરી હોય ત્યાં illustration તરીકે ઓળખાવવું.
- AIથી બનાવેલા staff, salon interiors, reviews કે haircut resultsને salonના actual staff, premises અથવા work તરીકે રજૂ ન કરવા.
- Before/after photosમાં AIથી haircut, beard, skin અથવા result બદલીને performance બતાવવી નહીં.
- AI દ્વારા identifiable customer/staff images edit કરવી હોય તો તે ઉપયોગ માટે તેમની મંજૂરી લેવી.

## 6. Hosting અને launch — developer સાથે નક્કી કરવાનું

- [ ] Domain જોઈએ? હોય તો domain name અને owner-managed DNS setupની વ્યવસ્થા.
- [ ] GitHub અને Vercel project કોણના accountમાં રહેશે, ownership અને maintenance કોણ કરશે તે નક્કી કરવું.
- [ ] Password/OTP મોકલવાના નથી; જરૂરી access invitation દ્વારા આપવો અથવા owner પોતે setup કરે.
- [ ] Final public domain મળ્યા પછી `SITE_URL` configure કરીને rebuild કરવું.
- [ ] Website પરથી WhatsApp bookingનો test ownerની જાણ સાથે કરી salonના phone પર message પહોંચે છે તે ચકાસવું.
- [ ] Mobile/desktop, calling, Maps, social links, rates અને imagesની final review.
- [ ] Clientનું written go-live approval.

## Clientને મોકલવા માટે ટૂંકો message

નમસ્તે! Joie Salonની website final કરવા માટે નીચેની વિગતો મોકલશો:

1. Official salon name, owner contact, booking WhatsApp number અને calling number.
2. Full address, Google Maps link, daily timings અને weekly off.
3. Actual services, rates, duration અને package details. Wedding/home service હોય તો તેની details.
4. Logo, shop outside/interior photos અને actual haircut/beard workના photos. શક્ય હોય તો before/after pairs પણ મોકલશો.
5. Team બતાવવી હોય તો actual names, roles અને photos; products વેચતા હો તો product details/photos.
6. Official Instagram/Facebook/YouTube અને Google review links.
7. Payment/advance/cancellation details અને website માટે પસંદગીની ભાષા.
8. Photosમાં દેખાતા લોકોની website ઉપયોગ માટે મંજૂરી અને final content/design approval.

Photos original qualityમાં Document તરીકે મોકલશો. Available information પહેલાં મોકલી શકો; બાકીની detailsની list સાથે final કરીશું.
